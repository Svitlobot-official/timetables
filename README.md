# Графіки відключень за групами — Світлобот

Відкриті дані [Світлобота](https://svitlobot.in.ua): графіки планових відключень світла
для кожної групи (черги) по регіонах. Оновлюються автоматично кожні 10 хвилин,
коли змінюється графік. Ліцензія — [CC BY 4.0](LICENSE): використовуйте вільно,
згадуючи «Світлобот» (https://svitlobot.in.ua).

## Файли

- `index.json` — список усіх груп, шлях до файлу і час останньої зміни.
- `<регіон>/<група>.json` — поточний тиждень групи, наприклад [`kyiv/37.1.json`](kyiv/37.1.json).
- `history/<понеділок>/<регіон>/<група>.json` — архів: стан кожного тижня.

Посилання на сирий файл:
`https://raw.githubusercontent.com/Svitlobot-official/timetables/main/kyiv/37.1.json`

## Картинки

Для кожної групи є дві картинки за постійними адресами, завжди актуальні
(посилання — у полях `image` і `image_today` в `index.json`):

- тиждень: `https://api.svitlobot.in.ua/timetables/kyiv/37.1.png`
  (або `…/kyiv/37.1/week.png`);
- сьогодні й завтра: `https://api.svitlobot.in.ua/timetables/kyiv/37.1/today.png`.

![Київ, група 37.1 — сьогодні й завтра](https://api.svitlobot.in.ua/timetables/kyiv/37.1/today.png)

![Київ, група 37.1 — тиждень](https://api.svitlobot.in.ua/timetables/kyiv/37.1.png)

Картинки не зберігаються в репозиторії, щоб він не розростався: вони малюються
з тих самих даних, що й JSON.

## Формат файлу групи

```json
{
 "region": "kyiv",
 "region_name": "Київ",
 "group": "37.1",
 "week_start": "2026-11-09",
 "updated_at": "2026-11-10T22:03:33+02:00",
 "source_updated_at": "2026-11-10T22:01:38+02:00",
 "days": [
  {
   "date": "2026-11-09",
   "weekday": "Понеділок",
   "slots": [0, 0, 1, 1, 1, 1, 1, 2, 0, 0, 3, 1, 1, 1, 1, 1, 1, 1, 0, 0, 1, 1, 1, 1],
   "outages": [["02:00", "07:30"], ["10:30", "18:00"], ["20:00", "24:00"]]
  }
 ]
}
```

- Тиждень — з понеділка по неділю, наростаючим підсумком: минулі дні лишаються такими,
  якими були, сьогодні й завтра — актуальні.
- `slots` — 24 значення, по одному на годину: `0` — світло є, `1` — немає всю годину,
  `2` — немає перші 30 хв, `3` — немає другі 30 хв.
- `outages` — ті самі відключення інтервалами `[початок, кінець]`; `[]` — відключень немає.
- `null` у `slots` / `outages` — графік на цей день ще не опубліковано.
- У неділю може з'явитися восьмий день — наступний понеділок, якщо графік на нього вже є.
- Час — київський (`Europe/Kyiv`); `updated_at` — коли графік змінився у Світлоботі,
  `source_updated_at` — час оновлення в джерелі.

## Джерела

Графіки не наші — ми збираємо їх з відкритих репозиторіїв, які парсять сайти обленерго.
Дякуємо їхнім авторам:

- [Baskerville42/outage-data-ua](https://github.com/Baskerville42/outage-data-ua) —
  Київ, Київська область, Одеса, Дніпро (ДТЕК);
- [yaroslav2901/OE_OUTAGE_DATA](https://github.com/yaroslav2901/OE_OUTAGE_DATA) —
  Черкаська, Чернігівська, Харківська, Хмельницька, Полтавська, Запорізька, Житомирська області;
- [szheliab/DNIPRO_CEK_PARSER](https://github.com/szheliab/DNIPRO_CEK_PARSER) — Дніпро (ЦЕК);
- [vn-progr/gpv-voe-vinnytsia](https://github.com/vn-progr/gpv-voe-vinnytsia) — Вінницька область.

Цей репозиторій додає до них тиждень наростаючим підсумком (минулі дні лишаються
такими, якими були), архів тижнів і картинки тижня.
